## 🌟 What is PremDevView (Prem Dev View)?

**PremDevView** (also referred to as **Prem Dev View**) is an open-source developer utility engineered by **Prem Sagar Pandey**. It is designed specifically for web developers and frontend engineers who want to preview and test their local development servers (e.g. `localhost:3000`, `localhost:5173`, `127.0.0.1:5500`, or Vite/React/Next.js/Live Server) inside an authentic virtual mobile phone screen without deploying or configuring external tunnels.

## ✨ Key Features

- 🚀 **Direct LocalHost Streaming:** Natively test `localhost:3000`, `localhost:5173`, `127.0.0.1:5500`, or any custom development port with zero latency.
- 📱 **Realistic Mobile Phone Frame:** Pixel-perfect virtual smartphone frame with authentic mobile dimensions, touch simulation, and bezel padding.
- 🔄 **Cinematic Orientation Switching:** Seamlessly toggle between Portrait and Landscape views with smooth hardware-accelerated animations.
- 🔙 **History Navigation Controls:** Dedicated Back (`<`) and Forward (`>`) buttons inside the preview for seamless multi-page app testing.
- 🔒 **100% Client-Side Privacy:** Everything runs entirely within your browser. No server logging, no analytics tracking, zero external proxies for local servers.

## 📖 How to Preview Localhost on Phone with PremDevView

1. **Start your local development server:** Run `npm run dev`, `npm start`, or open VS Code Live Server (`http://127.0.0.1:5500/`).
2. **Copy your local address or port:** Copy your localhost URL (e.g. `http://localhost:5173` or port number `3000`).
3. **Open PremDevView:** Visit [https://prem-dev-view.vercel.app/](https://prem-dev-view.vercel.app/).
4. **Paste and Launch:** Paste your URL into the address bar and click **Open Mobile Preview**.
5. **Test Responsiveness:** Test UI layouts, responsive breakpoints, and mobile interactions live with hot module reload.

## 🛠️ Run Locally

To run PremDevView on your local machine:

```bash
# 1. Clone the repository
git clone https://github.com/premsagarpandey/PremDevView.git
cd PremDevView

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```
