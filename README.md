## 🌟 What is PremDevView?

**PremDevView** is a fast, lightweight developer utility that replaces clunky browser device-modes. Simply enter your localhost URL or development port to instantly test responsive designs within an authentic mobile frame. 

---

## ✨ Key Features

- 🚀 **Direct LocalHost Streaming:** Natively test `localhost:3000`, `127.0.0.1:5500`, or any custom local port.
- 📱 **Realistic Phone Frame:** Pixel-perfect Android bezel with accurate mobile dimensions.
- 🔄 **Cinematic Orientation:** Smoothly flip between Portrait and Landscape views.
- 🔙 **History Navigation:** Built-in Back and Forward controls for seamless multi-page testing.
- 🔒 **100% Private:** Runs entirely client-side. No logging, no external tracking.

---

## 🛠️ Run Locally

If you'd like to run PremDevView on your own machine:

```bash
# 1. Clone the repository
git clone https://github.com/premsagarpandey/PremDevView.git
cd PremDevView

# 2. Install dependencies
npm install

# 3. Start the development server
npm run dev
```
