## 🌟 What is PremDevView?
**PremDevView** is an ultra-fast, lightweight developer utility created by **Prem Sagar Pandey** to help web developers test, inspect, and experience their **localhost and un-deployed web applications** inside an authentic virtual smartphone screen with zero friction.

Say goodbye to the clunky Chrome DevTools device mode — just enter your localhost URL or dev port and test your responsive designs in a distraction-free mobile frame.

---

## ✨ Key Features
- 🚀 **Direct LocalHost Streaming:** Test `localhost:3000`, `localhost:5173`, `127.0.0.1:5500`, and custom ports with native speed.
- 📱 **Real Phone Frame & Touch Simulation:** Pixel-perfect Android/mobile bezel with realistic dimensions.
- 🔄 **Cinematic Orientation Switch:** Flip effortlessly between Portrait and Landscape viewports with 60fps animations.
- 🔙 **History Navigation:** Built-in Back (`<`) and Forward (`>`) page navigation for multi-page web applications.
- 🔒 **100% Client-Side Privacy:** Everything runs locally inside your browser. No server logging, no tracking.
